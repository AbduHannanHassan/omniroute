- **feat(security):** add `REQUIRE_API_KEY_STRICT` feature flag (default off). When enabled together with `REQUIRE_API_KEY`, a dashboard session is no longer sufficient for API routes that dispatch to providers — only a valid API key is accepted, so nothing can be upstreamed without a key in the audit trail. The read-only model catalog (`/v1/models`) stays session-accessible so the dashboard UI keeps working; the dashboard playground and other session-based inference are disabled while strict mode is on. ([#0000](https://github.com/diegosouzapw/OmniRoute/pull/0000))
